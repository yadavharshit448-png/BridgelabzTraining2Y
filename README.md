# BridgelabzTraining2Y - Java Data Structures & Algorithms (DSA)

Repository for Java Data Structures & Algorithms coursework, lab assignments, and LeetCode problem solutions as part of the BTech CSE 2nd Year curriculum.

---

## 📁 Repository Branch Structure

Each topic has its dedicated branch for structured progression:

| Branch | Topic | Description |
| :--- | :--- | :--- |
| **`main`** | Fundamentals | Core Java DSA setup and basic algorithmic problems |
| **`arrays`** | Array DSA | Array manipulations, logical problems & LeetCode problems |
| **`02String`** | String DSA | String manipulation algorithms & LeetCode solutions |

---

## 🗂️ Project Directory Layout

```text
src/
├── Array/
│   ├── Leetcode/          # Array LeetCode problems with interactive Scanner input
│   └── Logical_Problem/   # Foundational array logical problems
├── Strings/
│   └── LeetCode/          # String LeetCode problems with interactive Scanner input
└── Java_dsa/              # Core Java practice (Palindrome, Prime, Digit counts)
```
